# Технологии ИИ: лабораторные работы

| ЛР | Тема | Файл |
|---|---|---|
| 1 | Повышение разрешения изображения (SRGAN, COCO) | `ТИИ ЛР1 Демченко МВ.ipynb` |
| 2 | Генерация карты по спутниковому снимку (pix2pix, maps) | `ТИИ ЛР2 Демченко МВ.ipynb` |
| 3 | Генерация текстового описания к изображению | `ТИИ ЛР3 Демченко МВ.ipynb` |

Задания лежат в `materials/`, статьи, по которым подбирались параметры (SRGAN, pix2pix, LSGAN, spectral normalization, EMA), в `papers/`.

## Запуск

Python 3.13, PyTorch (CUDA), torchvision, scikit-image, opencv-python, matplotlib, jupyter.

Датасеты (COCO val2017 и maps) скачиваются из самих ноутбуков в папку `data/`. Обученные веса сохраняются в `weights/`.
В репозитории лежат веса ЛР1 (`weights/lr1_*.pt`), поэтому раздел 9 ноутбука ЛР1 (свои фотографии из `photos/`) можно запустить без обучения.
Веса ЛР2 (по 217 МБ) в репозиторий не вошли, они получаются после запуска ноутбука ЛР2.
